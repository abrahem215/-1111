# دليل الاختبارات والتحقق البرمجي (Testing Guide)

## 1. اختبارات نسخة الكمبيوتر (Desktop PyTest)

تم تصميم اختبارات وحدوية شاملة تغطي منطق إيماءات اليد واختيار الحروف وإدخال النصوص دون الحاجة إلى وجود كاميرا فعلية:

### تشغيل الاختبارات:
```bash
cd desktop
pytest -v tests/
```

### المجالات المغطاة في الاختبارات:
1. `tests/test_layout_engine.py`:
   - فحص اختيار الحرف الصحيح بناءً على إحداثيات السبابة.
   - التحقق من عدم حدوث أخطاء عند خروج المؤشر خارج أبعاد لوحة المفاتيح.
   - التحقق من التبديل بين اللغتين العربية والإنجليزية.
   - اختبار أوامر المسافة والحذف والسطر الجديد.

2. `tests/test_gesture_engine.py`:
   - فحص تنعيم حركة المؤشر عبر فلتر الـ EMA لمنع الاهتزاز.
   - فحص منع تكرار الحروف عند استمرار المستخدم في ضم السبابة والإبهام.
   - فحص إيماءة الكف المفتوح لإيقاف الكتابة مؤقتاً.
   - فحص استجابة زر الإيقاف الفوري (Emergency Stop).

3. `tests/test_text_commands.py`:
   - التحقق من سلامة نصوص Unicode للحروف العربية والتشكيل.
   - التحقق من توافق ترميز UTF-16 المستخدم في Windows SendInput.

---

## 2. اختبارات نسخة أندرويد (Android JUnit)

### تشغيل الاختبارات عبر Gradle:
```bash
cd android
./gradlew test
```

### الحالات المختبرة في `GestureEngineTest.kt`:
- التحقق من دورة حياة آلة الحالات (IDLE -> PINCH_POTENTIAL -> TRIGGERED -> WAIT_RELEASE).
- التحقق من وجوب إبعاد الأصابع قبل قبول أي ضغطة جديدة.
- اختبار فلتر منع الاهتزاز.
- اختبار استجابة الكف المفتوح وزر الطوارئ.
