# دليل تثبيت وتشغيل AirType AI على أجهزة Windows

## المتطلبات الأساسية
- نظام تشغيل: Windows 10 أو Windows 11 (64-bit).
- لغة Python: إصدار 3.9 أو أحدث مثبت مع تفعيل خيار `Add Python to PATH`.
- كاميرا ويب (Webcam) مدمجة أو خارجية بدقة 720p أو أعلى وإضاءة جيدة.

---

## خطوات التثبيت خطوة بخطوة

### 1. الدخول إلى مجلد المشروع المكتبي
افتح موجه الأوامر (PowerShell أو Command Prompt) وانتقل إلى مجلد `desktop`:
```bash
cd desktop
```

### 2. إنشاء بيئة بايثون افتراضية (موصى به)
```bash
python -m venv venv
# تفعيل البيئة على Windows:
.\venv\Scripts\activate
```

### 3. تثبيت المتطلبات البرمجية
قم بتثبيت الحزم المطلوبة من ملف `requirements.txt`:
```bash
pip install -r requirements.txt
```

تحتوي الحزم على:
- `PySide6`: واجهة المستخدم الرسومية.
- `opencv-python`: معالجة والتقاط إطارات الكاميرا.
- `mediapipe`: تتبع 21 نقطة يد دون الحاجة لإنترنت.
- `numpy`: حساب المسافات الإقليدية ومصفوفات الصور.
- `pytest`: إجراء الاختبارات التلقائية.
- `pywin32`: توافق إضافي مع واجهات Windows.

## طريقة التشغيل واختبار الكتابة في المفكرة (Notepad)

### 1. تشغيل التطبيق
قم بتشغيل البرنامج عبر الأمر التالي:
```bash
python main.py
```

### 2. خطوات اختبار الكتابة في برنامج خارجي:
1. ستفتح نافذة **AirType AI** وتظهر شاشة الكاميرا في الجزء العلوي، مع لوحة المفاتيح الافتراضية في الأسفل.
2. ضع يدك أمام الكاميرا على بعد 40 إلى 70 سم.
3. ستلاحظ ظهور هيكل اليد ونقطة ملونة عند طرف السبابة تتبع حركتك بسلاسة.
4. حرك السبابة فوق أي حرف (مثل: "م" أو "س") لتلاحظ تظليل الحرف باللون السماوي.
5. افتح برنامج المفكرة (Notepad) وضعه إلى جانب البرنامج، ثم ضع مؤشر الكتابة داخل المفكرة.
6. في شريط أدوات AirType AI، اضغط على زر:
   **"تفعيل الإدخال في البرامج الخارجية (Windows SendInput)"** (سيتحول الزر إلى اللون الأخضر).
7. الآن، وجّه سبابتك نحو الحرف المطلوب، ثم **اضمم السبابة والإبهام معاً لمدة ثلث ثانية**:
   - سيومض الحرف باللون الأخضر ويظهر فوراً داخل برنامج المفكرة!
8. استمر في ضم إصبعك؛ ستلاحظ أن الحرف **لا يتكرر** بفضل آلية `WAIT_RELEASE`.
9. افتح أصابعك للانتقال إلى الحرف التالي.
10. اضغط على زر **🛑 إيقاف فوري** أو اضغط على مفتاح **F12** في أي لحظة لإلغاء الإدخال فوراً.
